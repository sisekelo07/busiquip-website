# ⚡ Quick Start - Go Live in 10 Minutes

## For the Impatient 😎

You have a complete website. Here's how to launch it **right now**.

---

## STEP 1️⃣ Local Test (2 minutes)

```bash
cd busiquip-website
npm install
npm run dev
```

Open [localhost:3000](http://localhost:3000) - Your site is there ✓

---

## STEP 2️⃣ Push to GitHub (2 minutes)

```bash
git init
git add .
git commit -m "BusiQuip website ready"
git remote add origin https://github.com/YOUR_USERNAME/busiquip-website.git
git push -u origin main
```

---

## STEP 3️⃣ Deploy to Vercel (1 minute)

1. Go to [vercel.com](https://vercel.com)
2. Click "New Project"
3. Select your GitHub repo
4. Click "Deploy"

**Your site is now LIVE! 🎉**

Get URL: `https://busiquip-website.vercel.app`

---

## STEP 4️⃣ Add Email (5 minutes)

1. Go to [sendgrid.com](https://sendgrid.com)
2. Sign up (free)
3. Create API key
4. Copy key
5. In Vercel: Settings → Environment Variables
   - Add: `SENDGRID_API_KEY = your_key`
   - Add: `CONTACT_FORM_TO_EMAIL = info@busiquip.com`

**Test contact form - Done! ✓**

---

## STEP 5️⃣ Custom Domain (Optional, 5 minutes)

1. In Vercel: Settings → Domains
2. Add your domain (busiquip.com)
3. Update DNS to Vercel nameservers
4. Wait 24 hours
5. Live at your domain ✓
